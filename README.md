# DUST DASH／砂けむりダッシュ

砂漠を走るオオミチバシリが、獲物を踏んで食べて加速し、天敵のタカから逃げ切るワンタップ・ランナーゲーム。
作者：Tanuki Box

## 遊び方
- タップ（PCはクリックかスペース）でジャンプ。空中でもう一度タップで2段ジャンプ。
- 虫・トカゲ・ヘビを上から踏むと食べて加速。着地せずに踏み続けるとコンボ。
- 画面上のスタミナは減り続け、減り方はだんだん速くなる。食べると回復。スタミナが少ないと足が遅くなってタカの影が迫り、0でバテてつかまる。
- 障害物は3種類：ジャンプでよける（岩・サボテン・穴）、2段ジャンプでよける（大サボテン・大穴）、ジャンプすると当たる（ハゲワシ）。穴に落ちるとその場でゲームオーバー。
- コインはジャンプの軌道どおりに並んでいる。たどって跳ぶと獲物に乗れる。速いほどコインの価値が上がる。
- ゲージがたまるとフィーバー（無敵ダッシュ）。
- コインで5種類の強化（スタミナ・スタートダッシュ・受け身・食いしん坊・金運）を買える。コイン・強化・最高記録はブラウザに保存される。
- みんなのランキング（距離・エンドレス・最高時速）。名前は「ことば＋生きもの」の組み合わせからえらぶ（自由入力なし）。参加した人の、名前と記録だけがサーバーに送られる。サーバーは Cloudflare Workers（`server/`、設定は `server/README.md`）。`config.js` の `RANK_API` が空のあいだはランキングを出さない。
- 遊んでいる途中で一時停止（右上のボタン・Esc キー・ほかのアプリに切りかえたとき）。つづけるときは 3・2・1 の合図。
- コースの上に、自分のベスト記録の旗。結果画面には、やられ方に合わせた「コツ」。
- ホーム画面に追加すると、アプリのように全画面で開ける（`manifest.webmanifest`・アイコン）。一度開けば、電波がなくても遊べる（`sw.js` がゲームのファイルをしまっておく。ランキングだけは電波が必要）。タイトルの右上に「アプリにする」ボタン（Android はインストールの画面、iPhone は追加のしかたの案内）。
- 700 m ごとにステージが進み、景色が変わる（全10ステージ：朝の砂漠・赤い峡谷・白い塩の湖・サボテンの森・夕焼けのメサ・砂あらしの荒野・星空の砂丘・月夜の岩山・夜明け前の峡谷・夜明けのオアシス）。台地や足場の上り下り、岩のひさし、つむじ風もある。
- ステージごとに名物がある（サボテンの森は「つむじ風に乗らないと越えられないサボテンの壁」、月夜の岩山は落石、星空は暗やみ、峡谷は谷渡り など）。ステージが変わるとマップ移動画面で、次の行き先と特色を見せる（エンドレスでは出ない）。
- 10ステージ目の終わり（7000 m）がゴール。逃げきるとエンディング。一度ゴールすると、タイトルで「エンドレス」（ゴールなしで景色がくり返す）を選べる。
- 大きなごほうびは宝石（サファイア・エメラルド・ルビー）。
- 結果画面の「シェア」で、記録の画像と文章を X などにシェアできる（公開 URL は config.js の SHARE_URL）。
- BGM と効果音はブラウザの中で作って鳴らす。右上のボタン（PCは M キー）で音を消せる。

## 自分のパソコンで動かす
`index.html` をブラウザで開くだけで遊べます（インターネットにつながっていると、丸い文字のフォントが使われます）。

## ファイルの場所
| 場所 | 中身 |
| --- | --- |
| `WBS.md` | 作業の一覧と進み具合 |
| `index.html` / `style.css` | ゲームの入れ物 |
| `js/common/` | Tanuki Box の共通土台（片手操作・日英切替・セーブ・効果音とミュート）。他のゲームでも使い回せる |
| `js/game/config.js` | 速さ・ジャンプ力・加速量などの調整用の数字 |
| `js/game/progress.js` | 強化の値段と効き目、セーブ |
| `js/game/course.js` | コースづくり（お手本の走りに合わせて、獲物・障害物・足場・コインを置く） |
| `js/game/story.js` | 初回のストーリームービー |
| `js/game/ending.js` | ゴール門とエンディングムービー |
| `js/game/mapscreen.js` | ステージが変わるときのマップ移動画面 |
| `js/game/share.js` | 結果のシェア（画像・文章・X の投稿画面） |
| `js/game/bgm.js` | BGM（楽譜と、それを演奏するしくみ） |
| `js/game/` | ゲーム本体（主人公・獲物・演出・画面の流れ） |
| `tools/build-single.js` | 全部を1つの HTML にまとめる道具（`node tools/build-single.js` → `dist/dust-dash.html`） |

## 公開のしかた（GitHub Pages・無料）
- このリポジトリは GitHub の組織 **TanukiBox** にある（TanukiBox/DUST-DASH）。
- ゲームの URL：https://tanukibox.github.io/DUST-DASH/ 。Tanuki Box のトップページ（https://tanukibox.github.io/ 、リポジトリ TanukiBox/tanukibox.github.io）からリンクしている。
1. リポジトリの Settings → General のいちばん下「Change repository visibility」で **Public（公開）** にする。
2. Settings → Pages → Build and deployment の Source を **Deploy from a branch** にして、Branch を今のブランチ（`claude/dust-dash-browser-game-kqs6r0`）、フォルダを **/(root)** にして Save。
3. 1〜2分待つと https://tanukibox.github.io/DUST-DASH/ で遊べる。以後、このブランチに push すると自動で更新される。
- X にリンクを貼ると、`assets/ogp.png` の画像つきで大きく表示される（`index.html` の og: / twitter: の設定）。
- シェアの文章に入る URL は `js/game/config.js` の `SHARE_URL`。

## 更新がスマホに出ないとき
ブラウザが前のファイルを覚えていることがある。`js/` や `style.css` を書きかえたら、`index.html` の `?v=4` の数字をぜんぶ1つ上げる（`?v=5` など。sw.js?v= も同じ数字になる）。
